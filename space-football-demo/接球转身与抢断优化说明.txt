1. 移动中主动接球
原问题是方向输入超过死区后直接绕过接球辅助，导致高辅助下手动移动也完全停止迎球。
现在为本方指定传球接收者预测未来约 2 秒内、脚下可触及的接球点，估算当前动量与加速度能否赶到。
低辅助仍保留手动接球；标准将方向输入与迎球路线各混合 50%；高辅助的迎球路线占 85%。
标准接应窗口 1.4 秒、高辅助 2.8 秒；窗口从出球开始计算，不保证拦截已经跑过或无法赶到的球。
靠近来球时身体逐步面向来球，第一脚触球不再瞬间扭转身体；领球方向仍读取玩家输入。
明显背离接球路线的强方向输入可覆盖辅助，松开方向可恢复同一传球的接应。
Backspace / 按下右摇杆，以及手动切人，取消本次自动接应。
拿到球后恢复玩家带球控制。球权仍通过真实碰撞取得，不扩大接球半径、不传送、不额外加速。
高辅助对非指定的附近低处自由球仅在无方向输入时帮助移动；门将仍可接应明确传给自己的球。
设置中的接球辅助与传球辅助独立；服务器与客户端预测均使用接球辅助设置。

2. 整体减慢转身
所有派生转身时间乘 1.6，角速度降低 37.5%；既有最大跑速和起步速度不在本轮改动。
180° 理论范围 224～352 ms；当前 386 人约 227.4～310.5 ms，平均 254.5 ms。
例如：梅西 233.5 ms、贝林厄姆 251.3 ms、哈兰德 264.4 ms、库尔图瓦 276.3 ms、范戴克 285.7 ms。
45°、90° 依转角比例缩短；八方向移动继续生效。60 Hz 模拟实际到位时间会向上取整到物理帧。
仍由灵活、加速、盘带、身高及力量派生，保留球员间差异；没有额外的按键等待锁。
完整资料：artifacts/player-turning.json、artifacts/球员转身时间一览.txt。
这些是可调整的游戏手感参数，并非真实运动学测量。

3. 三类防守动作与键位
普通抢断：键盘 D / Xbox B（持球时同键射门）。站立短促伸脚、收腿，总动作约 0.50 秒。
原地铲球：键盘 A / Xbox X，起铲前向速度低于 1.2 游戏单位/秒时自动采用；降低重心原地伸腿，约 0.78 秒。
跑动滑铲：相同的 A / X，达到上述速度时采用；延长伸腿、滑行、收腿起身，约 1.05 秒。
按下时确定动作，松键不会误触射门或挑传。恢复期不可连续重置抢断动作。
铲球根据实际速度自动分型；仅按住冲刺键、尚未跑起来时不会获得长距离滑铲。
当前前向速度取实际速度在身体朝向上的分量，上限为该球员基础速度的 1.42 倍；避免急转身时凭空反向冲刺。
跑动滑铲目标速度在 0.65 秒内线性衰减到零，其后起身；不再给固定向前速度增益。
低速原地铲球快速刹住既有残余动量，静止时没有前冲。场地边界及其他球员碰撞仍会限制实际距离。
同一球员、无碰撞的 60 Hz 测试：起铲速度 0 / 0.8 / 4 / 8，对应滑行距离约 0 / 0.004 / 1.27 / 2.53 游戏单位。
游戏单位不等同于现实米；本轮参数先用于实测，再根据场地节奏调整。

4. 判定、动画与联机
按键先启动动作，约 90 ms 后才进入接触窗口；普通抢断窗口约 90～230 ms，原地铲球 90～320 ms，跑动滑铲 90～560 ms。
触球检查朝向、距离和球高；抢断能力与护球强度影响可触及距离。一次动作最多结算一次有效抢断或犯规。
铲球只处理低球；不能隔着对手身体吸走足球。先碰身体或球已被传走后的危险接触沿用犯规、黄红牌规则。
成功抢断先把球捅向可争抢的空间，不立即把球吸到抢断者脚下；动作进行中也不被普通接球覆盖。
原地铲球和滑铲分别调整重心、伸腿、支撑腿及起身姿态，脚部目标贴地；手臂参与平衡。
动作目前使用现有人体骨骼与程序化动画，没有引入动作捕捉资源。
权威服务器执行接触判定，客户端预测复用相同滑铲减速公式；快照同步动作分型与起铲速度。

实现入口

football_motion.gd：防守动作时长、接触窗口及滑铲减速。
player_ratings.gd：全局转身时间倍率。
match_mechanics.gd：第一脚触球、取消接应、额外状态同步。
match_network.gd：独立接球辅助与防守动作预测、动作编码。
skinned_player.gd：普通抢断、原地铲球、滑铲及起身骨骼姿态。
main.gd / play_assistance.gd：动作提示、操作帮助与辅助描述。
结构化结果：artifacts/receiving-defending-verification.json。
