本次比赛核心升级
1. 移动有加速、减速、转向过程；冲刺消耗当前球员体力，停止冲刺后恢复。
2. 带球有步幅变化；冲刺趟球更远。接球短暂调整步伐，足球有独立高度、重力与弹跳。
3. 短传依据输入方向、队友空当和传球线路选择目标；直塞送到队友前方。
4. 主动抢断需要方向和距离，落空后有恢复时间；高速球可以被封堵折射。
5. 队友拉开两翼、前锋接应、后卫保护；持球 AI 选择绕过防守或向前传球。
6. 连续人体网格与蒙皮骨骼表现跑步、接球、传射、抢断和扑救，体型匹配所选球员身高与力量。
7. 经典规则采用脚踢界外球、角球、门将球门球、犯规、直接/间接任意球和点球，无越位；详见《比赛机制说明.txt》。
8. 星际规则可在舰桥 / 快速练习中切换，保留边墙反弹、太阳风和决赛高速球。

键盘
方向键：移动，并为传球选择接应方向。比赛中 WASD 不再移动。
D 持球时按住、松开：蓄力、射门。上下方向键选择球门角度，目标光环显示瞄准位置。
S：定向短传。W：直塞。传球按住蓄力，松开出球；轻点可快速传球。
Z + D：弧线射门；保持 Z 按下，松开 D 完成射门。
Q：防守切人，进攻轻点呼叫前插；Z：进攻轻点呼叫接应，防守按住协防。自动切人可单独设置。
E 按住：冲刺。C 按住：防守横移，面向足球。
D 无球时按下：主动抢断；看准球的方向和距离，不能连续无间隔抢断。
射门 / 抢断共用一键，按下时决定动作；抢断后松键不会额外射门。
A：挑传 / 无球铲球；低速时原地铲球，跑动时滑铲，起铲的前向速度越高滑行越远。Q + D：吊射；Q + W：挑直塞；蓄力 D 中按 S：假射。
高空球接近自身可触及范围时按 D：根据球高选择头球或凌空射门。旧空格、J、R、Tab 比赛动作已移除。
1 / 2 / 3：防守、均衡、压上战术。
Esc：菜单。单人比赛暂停；联机比赛继续运行。
F1：操作指南。F11：全屏 / 窗口。
菜单仍支持方向键 / WASD 选择、Tab 切换、Enter / 空格确认、Esc 返回。

手柄（Xbox 标准按键名称）
左摇杆：移动与传球方向，有模拟速度和死区。
B 持球时按住、松开：蓄力射门；无球时按下：抢断。A：短传。Y：直塞。A / Y / X 按住蓄力，松开出球。
RB + B：弧线射门；保持 RB 按下，松开 B 出脚。PlayStation 为 R1 + ○。
LB：防守切人，进攻轻点呼叫前插。RB：进攻轻点呼叫接应，防守按住协防。RT：冲刺。LT：防守横移。Menu：比赛菜单。View：操作指南。
十字键左 / 右：在防守、均衡、压上之间向防守 / 进攻方向逐档调整。
X：挑传 / 无球铲球；原地与跑动滑铲自动按当前前向速度区分，无需额外组合键。LB + B：吊射；LB + Y：挑直塞；蓄力 B 中按 A：假射。
高空球可触及时按 B：头球 / 凌空射门。
使用 Godot 标准手柄映射；启动优先 Xbox，运行时选择最近有效输入的活动手柄。
自动测试覆盖按键和菜单路由；已检测到 XInput 手柄，但没有声称进行实体按键手动实测。

比赛与成长
足球轨迹：确定性简化物理包含重力、空气减速、地面摩擦、落地反弹和旋转衰减。
弧线射门增加空中侧旋，使用方向输入选择弯曲一侧；普通传射仍以直线方向为主。
传中、挑传、挑直塞、吊射使用同一重力与阻力积分；这不是完整空气动力学或旋转刚体模拟。
足球半径从 0.47 改为 0.30，同时调整落地高度、球面线条和地面投影。
门将横移时面向来球，按射门轨迹预测拦截位置，并使用预备、侧扑恢复、接抱球和手抛球姿态。
门将扩大禁区内脚下与伸手控制范围，主动收集自由球、回追身后球；对方明显更早能到球时优先保护球门。
同一帧内先扑到球再越过门线的情况，现在先结算扑救；已经过线的球不能被门将追回取消进球。
普通来球与队友回传默认脚下接球，自动切换到门将，可带球转向，不会自动手抛球。
方向键 + S / 左摇杆 + A 定向短传，A / X 挑传，支持三档传球辅助；球门球也从地面踢出。
面对对方射门等真正扑救时，禁区内仍可接抱球；人类控制时等待方向与传球指令再出球。
弧线、门将脚下/手持状态和动作由服务器同步。
新增操作辅助：主页设置、本地暂停菜单或联机菜单 → 操作辅助与传球指示。
低接球辅助保留手动跑位；标准辅助在移动中适度修正迎球路线，高辅助修正更强，仍可保持方向输入。
高辅助也会在没有方向输入时帮助争取附近低处自由球；不会强制截走手动追球方向。
明显背离接球路线的强方向输入可退出迎球修正，松开后可继续接应；手动切人或取消键终止本次接应。
接球辅助可单独调整，不要求与传球辅助相同。辅助不会提高球员能力，也不会自动射门。
脚下小箭头显示修正后的短传方向；短传 / 直塞出脚后短暂显示实际出球方向。
方向指示可独立开关，设置自动保存；联机双方可使用各自的辅助等级。
详细行为与范围见《多端输入说明.txt》。

每队 1 门将 + 4 名场上球员。原有球星与范戴克保留。
战役 / 快速练习每场 100 秒；联机每场 180 秒。
计时器现在显示实际剩余时间，进球和重新开球期间暂停计时。

战役胜利解锁下一站；失败或平局可以保留成长后重赛。
训练仍提高球员速度，门将签约提高门线移动速度。
快速练习与联机结果不改变战役星币、升级或存档。
联机双方使用相同球员能力，不带入单人升级或星际环境效果。

联机
两位玩家都从主菜单进入“1 对 1 联机对战”。
一方创建房间，另一方填写地址与端口后加入。双方点击“准备开球”。
同一台电脑的第二个实例使用 127.0.0.1；两台局域网电脑使用房主局域网 IP。
默认端口 28765 / UDP。跨互联网需要可访问服务器和对应网络配置。
本次未部署公网服务器，也没有修改系统防火墙或路由器设置。
房间可以连续再战；离开或失去连接会结束当前对局，不计战役奖励。
在线打开帮助或菜单时，比赛不会暂停。

专用服务器
可运行根目录 Start-Space-Football-Server.cmd，在控制台按 Ctrl+C 停止。
专用服务器使用现有 Godot 控制台程序，无需显卡，不创建渲染场景。
两个客户端填写该服务器地址后加入，双方准备后开始。
源码命令：godot.cmd --headless --path space-football-demo -- --server --port=28765
导出的独立程序也支持 --headless -- --server --port=28765。
当前专用服务器承载一个房间；不是账号、自动匹配或多房间运营服务。

网络与代码结构
match_sim.gd：固定 60 Hz 的权威比赛逻辑、双方输入状态、规则和 AI。
match_network.gd：ENet 房间与准备、20 Hz 紧凑状态包、可靠动作消息、对局编号、结算与断线。
football_input.gd：键盘 / 手柄输入转换，同一次按键只生成一次动作。
skinned_player.gd：连续蒙皮人体与程序化比赛动作。
match_rules.gd / rules_presentation.gd：权威判罚、定位球流程、停表与庆祝表现。
main.gd：界面、三维场景、音效、镜头与模式流程。
campaign.gd：战役、训练、签约、奖励、旧存档迁移。
服务器决定球权、进球和移动；客户端只发送输入，不上传比分或权威坐标。
客户端对自身移动做预测与校正，对远端状态做短时外推和平滑。
足球与抢断仍以服务器判定为准，尚无完整的球体回滚和历史碰撞补偿。
