YFFM3 · 比赛机制扩展 · 2026-10-03
本文件说明当前源码版本；此前的“未接入”记录以本文件为准。

1. 传接球与操作时序
短传、直塞、挑传改为按住蓄力、松键出球。轻点仍能快速传球；力度改变球速，高球还改变飞行时间。
RB + A / Z + S 为大力地滚球；RB + X / Z + A 为低平传中。
传球约 70 ms、射门约 55 ms 的出脚准备之后释放足球，预备与随摆动画衔接，松开射门键后不再继续增加力量。
己方传球即将到达当前接球队员时，可预按并松开传射键；预输入约 0.4 秒有效，接到球后执行一次。
切人、丢球、过期、暂停、取消都会清理待执行动作。来球接近可争顶范围时，射门键优先发起争顶。
Backspace / 按下右摇杆：取消待执行动作。蓄力射门中按短传仍是假射。
第一脚触球读取停球能力、来球速度、身体朝向、对手压力；方向输入用于顺势领球。高速球可能停大，产生可争抢的自由球。
标准 / 高接球辅助现在也会在方向输入期间修正迎球路线；明确反向跑开可覆盖辅助，取消键或手动切人终止接应。近球时逐步面向来球，第一脚触球不会瞬间扭转身体。
当前没有新增逆足星级惩罚；缺失原始资料继续保留空值。

2. 切人与盘带
无球：右摇杆方向切人；键盘默认小键盘 8 / 2 / 4 / 6，选项可切为 I / K / J / L。
Q / LB 的防守切人继续保留，并考虑球门侧位置；队友头顶“▽”显示下一位候选，没有脚下圆圈。
持球：方向操作键执行拉球变向；E / RT + 方向操作键进行趟球突破，足球离脚后允许双方争抢。
自动切人分为手动、接球队员、接球与自由球；主动移动或主动取消接应优先，不用自动切人覆盖主动防守。

3. 队友指令
进攻轻点 Q / LB：呼叫面向方向的队友前插。
进攻轻点 Z / RB：呼叫队友靠近接应。
防守按住 Z / RB：呼叫一名 AI 队友协防；松开结束，低体力球员不参与。原 AI 压迫者交接保护职责。
Q + S / LB + A 二过一继续保留；组合键不会额外误触发轻点跑位。
头顶文字标明被请求的跑位者和协防者。输入优先级与现有球队规划共用。

4. 空中与身体对抗
高球 D / B：头球或凌空攻门；S / A：摆渡；A / X：解围。
起跳速度由弹跳决定，使用实际腾空高度检测触球；起跳、腾空、落地都有动作与短时恢复。
26 项能力现在全部参与比赛或 AI；弹跳不再只是资料展示，也不会直接扩大站立接球范围。
护球 / 横移时有侧身身体对抗，力量差、相对移动与护球状态影响失衡、减速及球是否脱离。
高速危险背后铲抢可直接红牌；普通危险铲抢记黄牌，两黄变红；合法先触球仍沿用原判定。
普通抢断 D / B 为站立伸脚；铲球 A / X 按前向速度选择原地伸腿或跑动滑铲，滑行继承速度并衰减，不额外加速。接触窗口、单次命中、身体先触碰、落空恢复和起身均已接入。
所有球员的转身时间统一乘 1.6，转向角速度降低 37.5%，当前球员库 180° 约 0.227～0.311 秒；最大跑速不随此次调整改变。
门将扑挡倾向把球导向侧面，保留能量衰减；原脚下接球、手持球方向分配、扑倒起身和再次扑救继续共用既有状态。

5. 疲劳、替补与减员
比赛菜单 → 替补席：选择场上球员和替补，下一次重新开球准备时执行。单人菜单暂停，联机菜单不暂停。
每队暂自动补充 4 名替补（门将、前锋、边路、后卫），全场替补不与双方首发重复；开发阶段未增加赛前替补编队页。
短时体力继续控制冲刺。整场疲劳缓慢累积，对最高移动速度提供有上限的小幅影响；替补席逐步恢复疲劳。
换人替换完整资料、能力、体型、动作惯用脚和模型；黄牌跟随球员，重新上场不会洗掉黄牌。
红牌球员不得重新登场；减员计时为 120 秒有效比赛时间，满足人数条件的失球可提前结束减员；在下一次死球补员。
门将被罚下时，用替补门将替换一名外场球员，保持少一人的人数；少于 3 人结束比赛。
当前是短局适配规则，补员使用死球时点，没有制作场边换人区往返动画。

6. 定位球与裁判
定位球 4 / 十字键上：更换主罚。5 / 十字键下：轮换短接应、近点、后点配合。
等待主罚时队友会按方案移动；点球和累计犯规罚球保持专用站位。
有利原则保留短暂进攻机会；失去球权会回到原犯规地点，犯规只累计一次。
累计第 6 次起，非禁区犯规使用无墙累计犯规罚球；原禁区犯规仍为点球。
“门将 4 秒 / 重复回传限制”是独立开关，下场生效；普通接球继续默认脚下处理。
联机由房主选项决定，专服可加 --strict-rules；客户端设置不改变服务器规则。
赛制仍为短局加金球加时，没有宣称完整官方室内五人制规则。

7. 辅助、反馈与开发工具
操作辅助 → 分别调整：接球辅助、射门辅助、自动切人、震动、进球回放、门将规则、方向键盘布局。
原低 / 标准 / 高预设保留，可批量调整；传球辅助继续由主预设控制，各项修改分别存档。
手柄震动可关闭；传球、碰撞、射门、门柱有事件音效。实体手柄手感仍需玩家实测。
进球阶段约 5 秒停表：先显示约 0.65 秒 Goal 动画，再播放约 3.95 秒进球回放，结尾短暂保留越线画面。
回放记录最近约 3.75 秒的位置、朝向、动作和球轨迹，补齐足球越过门线的一帧并插值播放；进球队员底部圆圈、举手庆祝和球员拉近特写已移除。
传射键跳过回放；回放只改变本机画面，不回滚服务器，不增加联网等待时间。
本地快速比赛 F2 保存当前训练场景，F3 重试，包含完整比赛状态和随机数状态；恢复时清掉玩家尚未释放的输入，联机禁用该工具。

8. 联机与验证入口
新增方向、力度、协防、辅助设置、替补请求均通过统一命令传到权威端，并进行范围校验。
快照包含起跳高度、疲劳、黄红牌/减员、替补身份、请求角色；采用有解压上限的压缩包。
客户端预测同步疲劳、腾空、落地、失衡及出脚准备的移动系数。
安卓输入接口预留相同命令字段，本轮没有安装、测试或打包安卓，也没有导出 Windows 安装包。
新协议需双方均重启最新开发工程；不与此前已打开的旧版本混用。

新增专项：godot.cmd --headless --path space-football-demo --script mechanics_tests.gd
完整回归：godot.cmd --headless --path space-football-demo --script tests.gd
2K 画面：godot.cmd --path space-football-demo --fullscreen --resolution 2560x1440 -- --verify-mechanics
键鼠/手柄：godot.cmd --path space-football-demo --fullscreen -- --verify-input
新增机制联机：powershell -File space-football-demo/verify-network.ps1 -Mechanics -Rounds 2
原规则联机：powershell -File space-football-demo/verify-network.ps1 -Rules -Rounds 1
测试截图、日志位于 artifacts。自动输入与固定场景回归不能替代真实对抗的长期平衡与手感测试。
