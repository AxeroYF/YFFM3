群星绿茵 · 多端输入规划与电脑端操作（2026-10-03）

当前交付范围
电脑客户端支持键盘、鼠标和手柄，优先适配 Xbox / XInput。
安卓仅保留输入适配接口；未制作触屏布局，未进行安卓测试、依赖安装或打包。

电脑菜单
键盘：方向键 / WASD 选择，Tab / Shift+Tab 切换，Enter / 空格确认，Esc 返回。
Xbox：左摇杆 / 十字键选择，A 确认，B 返回，Menu 在比赛中暂停或恢复。
选中按钮显示高亮边框，确认键徽标放在按钮文字右侧并保持在按钮内部；主菜单主按钮图标放大。
比赛中的暂停与操作指南快捷键图标也放在对应按钮内部。
主页、设置、暂停、在线菜单、球队、球员库和详情弹窗使用同一套导航。
弹窗焦点不会进入底层页面，关闭后恢复原选择。不可用按钮自动跳过。
加载界面显示当前阶段及进度，暂时拦截菜单和比赛输入，完成后重新启用操作。
搜索框输入 WASD 不会导航；Tab 或上下键可离开输入框。
位置筛选框：手柄 A / 键盘 Enter 轮换，左右键调整；鼠标可打开下拉列表。

Xbox 比赛
左摇杆：移动和瞄准。
A：短传；Y：直塞；B：持球时按住蓄力、松开射门，无球时按下抢断。
LB：无球切人；RT：冲刺；LT：防守横移。
十字键左 / 右：在防守、均衡、压上三档中向防守 / 进攻方向逐档调整。
Menu：暂停菜单；View：操作指南。
X：持球挑传 / 传中，无球铲球。采用 FIFA Classic 手柄的核心攻防键位；B 普通抢断，X 铲球。
同一个 X 按当前前向速度选择原地铲球或跑动滑铲；速度越快滑行越远，过程中减速，再收腿起身。
RB + B：弧线射门。按住 RB，按住 B 蓄力并松开 B；最后松开 RB。
LB + B：吊射；LB + Y：挑直塞。保持 LB 按下完成出球。
LB + A：二过一传球并前插；持球 LT：护球；防守时按住 Y：门将出击，松开回位。
蓄力 B 时按 A：假射；可触及的高空球附近按 B：头球 / 凌空射门。
右摇杆方向：无球切人，持球拉球变向；RT + 右摇杆：趟球突破。按下右摇杆取消待执行动作。
A / Y / X 按住蓄力、松开出球。RB + A：大力地滚球；RB + X：低平传中。
进攻轻点 LB / RB：呼叫前插 / 靠近接应；防守按住 RB：队友协防。
高球 A / X / B：摆渡 / 解围 / 攻门。定位球十字键上 / 下：更换主罚 / 跑位方案。

键盘比赛（纯键盘方向键方案）
方向键：移动和瞄准；上下方向调整射门落点。
S：短传；W：直塞；D：持球时按住蓄力、松开射门，无球时按下抢断。
Q：无球切人；E 按住：冲刺；C 按住：防守横移。
Z + D：弧线射门。按住 Z，按住 D 蓄力并松开 D；最后松开 Z。
1 / 2 / 3：直接选择防守 / 均衡 / 压上；Esc：菜单；F1：指南；F11：全屏。
A：持球挑传 / 传中，无球铲球；与手柄共用速度分档。D 普通抢断，A 原地铲球 / 滑铲。Q + D：吊射；Q + W：挑直塞。
Q + S：二过一；持球 C：护球；防守时按住 W：门将出击，松开回位。
蓄力 D 时按 S：假射；可触及的高空球附近按 D：头球 / 凌空射门。
比赛中 WASD 不再移动，空格不再射门。
小键盘 8 / 2 / 4 / 6（可选 I / K / J / L）：无球方向切人、持球拉球；E 修饰为趟球突破。
传球键按住蓄力、松开出球；Z + S / A：大力地滚球 / 低平传中。
轻点 Q / Z：前插 / 接应；防守按住 Z 协防。Backspace 取消；定位球 4 / 5 更换主罚 / 跑位。
本地快速比赛 F2 保存训练场景、F3 重试；比赛菜单内可以申请换人。
比赛与菜单分开路由：菜单仍支持 WASD、方向键、Tab、Enter / 空格和 Esc。
射门 / 抢断按下时确定动作；抢断后夺回球权再松键不会射门。
蓄力中丢球、切人、假射或改挑传/直塞会取消蓄力；暂停和设备切换也清理状态。

设备状态与图标
启动时识别已连接手柄，优先选择 Xbox。运行期间支持连接和断开。
界面显示控制器名称、连接情况与当前输入方式。
键鼠和手柄提示随最近的有效输入切换；轻微摇杆漂移不会切换设备。
Xbox 使用 A/B/X/Y、LB/LT/RT；PlayStation 使用 ×/○/□/△、L1/L2/R2。
Nintendo 显示对应物理位置的 B/A/Y/X；未知手柄使用上下左右位置标识。
设置 → 按键图标可覆盖自动识别，偏好保存至 user://input-preferences.cfg。
切换图标不会重新映射按键。型号识别依赖系统返回的名称；兼容模式可能报为 XInput。
当前仅实际检测到 XInput Controller，PlayStation/Nintendo 映射不代表已做相应硬件实测。

操作辅助与传球方向指示
入口：主页 → 设置 → 操作辅助与传球指示；本地暂停菜单、联机菜单也可直接进入。
默认标准辅助，传球方向指示默认开启；键盘和手柄共用同一偏好并自动保存。
低辅助：方向优先，在约 15 度范围内寻找队友，仅进行小幅方向修正；接球需要主动跑位。
标准辅助：约 38 度范围选择接应队友，修正大部分传球角度；接球时把方向输入与迎球路线各混合 50%，最长 1.4 秒。
高辅助：扩大到约 65 度范围并对准目标；接球时迎球路线占 85%，最长 2.8 秒，移动中也能主动接球。
附近自由球的辅助只在没有方向输入时触发，范围 4 游戏单位内且来球较低；不覆盖主动追球方向。
标准与高辅助在未输入方向时自动选择队友；低辅助使用球员面朝方向。
基础球速根据传球距离计算，叠加玩家按住时间的力度系数；自动切人现在可独立设为手动、接球队员、接球与自由球。
明显背离接球路线的强方向输入可以退出迎球修正，松开后可恢复本次接应；手动切人或取消键终止接应，拿到球后不自动带球。
不会自动冲刺、抢断或射门，不提高球员速度、能力值或接球半径，传球仍受球员能力误差影响。
“分别调整辅助”可单独设定接球辅助、射门辅助、自动切人；非操控队友仍使用球队 AI 分工。
脚下小箭头预览辅助修正后的短传方向，实际传出短传 / 直塞后在传球者脚下保留实际出球方向 0.3 秒。
蓄力射门时隐藏传球箭头；主菜单、暂停和帮助界面不显示。指示开关不改变传球计算。
联机双方可以独立选择等级，服务器校验并执行；客户端预测使用同一套接应计算。
打开在线菜单或输入超时后不自动迎球；对局仍在服务器继续进行。
偏好保存在 user://input-preferences.cfg 的 gameplay 项；安卓适配器尚未落地。

输入边界
菜单确认不会穿透成传球或射门。
暂停、输入来源切换、当前手柄断开会清理蓄力状态，孤立的松键事件不会触发射门。
本地比赛在手柄断开时暂停；在线比赛打开菜单并发送取消指令，服务器继续比赛。
窗口失去焦点后不响应手柄菜单输入。
一位玩家使用当前活动手柄；这不是同机双人控制模式。

后续安卓入口（尚未落地）
input_provider.gd 定义 sample() 和 reset()，football_input.gd.external_provider 可接入新适配器。
sample() 输出现有统一比赛指令：move、sprint、jockey、action、aim、tactic。
可选指令：finesse（弧线）、chip（吊射/挑直塞/二过一修饰）、keeper_rush（按住门将出击）。
扩展字段：power（0～1）、direction（方向切人 / 技巧）、driven（大力球）、contain（协防）、out / reserve（换人索引）。
接球、射门、自动切人设置由 football_input.gd 在采样时统一添加；新增动作位定义集中在 match_mechanics.gd。
单次动作只提交一次，按住时间由适配器转换为力度，取消触摸必须清理待释放动作。
move 限长至 1；键盘斜向与直向最高速度一致，手柄保留连续模拟角度。转身由权威模拟和客户端预测统一处理。
未来触屏适配器应负责独立多指指针归属、虚拟摇杆、按住/松开射门、滑动瞄准、
取消触摸、刘海安全区、按键布局与尺寸设置；由它采集输入，不改变服务端比赛规则。
当前没有实例化移动端适配器，也没有把桌面按钮布局声明为可用的触屏方案。
