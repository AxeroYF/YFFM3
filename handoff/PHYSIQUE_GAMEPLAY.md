# 体型与比赛手感

更新：2026-10-04。用户要求把模型体型接入实际操作，差异稍明显但不要过大。以下为机制开发时记录；代码后续已在 `6f6c19e` 提交并推送，未打包。最新状态见 CURRENT_STATE.md。

## 已接入的行为

- 启动与刹车：紧凑体型更容易启动、收步。反向输入先消除原方向速度，再用剩余帧时间向新方向加速；斜向切入保留短暂横向惯性，不能通过反复变向叠加速度。
- 转身：身高、腿身比例、肩腰厚度共同形成有限的惯性修正，替代旧的身高/力量转身惩罚，避免重复计算。原地 180° 理论时间仍限于 224–352 ms；跑动时再适度降低转身角速度，极端上界约 396 ms。没有输入延迟计时器。
- 步幅与带球：实际腿长继续驱动骨骼和步频；新增腿长对带球触球间隔、冲刺趟球距离的轻微修正。最高跑速、全局 0.78 跑速系数和 1.42 冲刺倍率保留。
- 护球、对抗：力量仍是基础，体型只补充护球值及失衡恢复；相对体量参与重叠分离，宽厚者被挤开的份额略小。分离仍受每人每帧 `speed × 0.20 × dt` 总预算约束，不改写速度，不产生连环碰撞加速。AI 的身体卡位使用其实际横移防守状态，避免依赖人类队伍输入。
- 伸脚：长腿适度增加地面接球与抢断范围，仍要满足球高、面对方向、动作触球时机和身体犯规判定。胸部碰撞宽度按体型小幅调整。没有再叠加头球或门将的垂直触球高度。
- 动画：根据实际显示速度的变化添加小幅启动前倾、刹车回收和侧向倾斜；仅倾斜躯干，腿部仍用原 IK 落脚。停下后即使网络旧快照仍带速度，也不会持续跑步或倾斜。
- 辅助与联机：接球辅助、AI 拦截预判考虑先刹车再加速；权威模拟和客户端预测共用运动函数。球员 ID、换人和网络恢复均从同一体型推导比赛数值。

## 数据边界与调参入口

`player_physique.gd` 是体型修正集中入口，`player_movement.gd` 是共享运动/拦截距离公式，`player_ratings.gd::for_player()` 负责原能力与身体参数组合。

全部 386 人使用已有身高和腿长基础；67 名首批传奇另外使用逐人配置的肩宽、躯干厚度、胯宽和腿身比例。其余人没有新增逐人美术配置。原球员库及 26 项能力不变。体型为美术和游戏设计近似，不是医学重心、真人体重或测量资料；肤色、脸型、发型、姓名、国籍不参与计算。

| 派生项 | 相对能力基础值的体型修正边界 |
| --- | --- |
| 加速度 | ±8% |
| 刹车强度、原地转身时长 | 各 ±10%，转身另受全局时长上下限限制 |
| 普通高速转身角速度 | 原地的 89%–100%；门将及横移姿态影响更轻 |
| 抢断伸脚范围 | −6.5% 至 +7% |
| 原有脚下接球范围 | ±2.5% |
| 原有碰撞半径及胸部宽度 | ±3.5% |
| 带球步幅 | ±3.5% |
| 护球强度 | 归一化力量值上叠加 −0.070 至 +0.085 |
| 失衡稳定性 | 0.90–1.12 倍 |
| 相对碰撞体量 | 0.84–1.20 倍，仅用于分摊位移；不是公斤 |

游戏内：球员库 → 球员资料，可查看启动、刹车、伸脚体型修正，以及原地转身时间。模型展厅保留原入口。

## 同能力对照与实际卡库示例

将梅西与哈兰德的所有能力临时设为相同的 80，仅用于测试副本；以下是 120 Hz 固定步长、满体能、无球、直线输入。启动指 0 到常规跑速 95%；刹车距离从满冲刺松开方向开始，按 `1.45 场地单位 = 1 米` 换算。都是游戏测量值。

| 同能力的体型 | 启动 | 冲刺刹车距离 | 原地 180° | 抢断范围 |
| --- | --- | --- | --- | --- |
| 梅西，170 cm | 283.3 ms | 0.944 m | 235.9 ms | 1.447 m |
| 哈兰德，195 cm | 308.3 ms | 1.056 m | 262.7 ms | 1.574 m |

差异约为启动 9%、刹车距离 12%、转身时长 11%、伸脚范围 9%。实际卡库还叠加球员原有能力：梅西原地 180° 224 ms、哈兰德 265.3 ms；马拉多纳低重心而较厚实，兼具刹车和护球优势，不能用身高单一排序。

## 验证

- `physique_tests.gd`：**1,995 项通过**。全库修正边界、颜色/头脸等不影响物理、跨位置一致、同能力体型对照、能力值仍占主导；30/60/120 Hz 刹车一致；反向与八向移动不增速；拦截距离与实际积分一致；真实抢断边界、侧向对抗、碰撞分离预算；18 组服务器/预测动作轨迹一致；换人快照恢复；原库不变。
- `legend_models_tests.gd`：**608 项通过**。原骨骼/塑形检查继续通过，碰撞断言更新为有界体型修正，垂直头球高度仍来自源身高。
- 原八组机制回归：**1,151 项通过**，其中 `tests.gd` 531 项、12 个 AI 对局共 30 球、三个自动操作对局全部正常终场。合计无窗口检查 **3,754 项**。
- `--verify-physique`：**11 项通过**。原生 2560×1440 资料页显示/布局、实际两名传奇换人建模、启动和刹车倾斜、停下后的动画归零。已查看资料、启动和跑动截图。`--verify-locomotion` 也重新通过：实际位移速度与动画速度一致，步频依次增加，停止归零。
- 协议升级为 **4**，双方需同版本。玩家主机 + 客户端（自定义阵容）和独立服务器 + 两客户端（冰球模式）分别完成两轮真实 ENet 测试；均启用机制验证，包含接球、抢断、滑铲、换人等；一端上行 100 ms 延迟、每五包丢一包，比分与终场帧一致。
- 本机日志仍有已知 Windows 沙箱 CA 证书库读取错误。网络验证默认仍遇错失败；可显式传 `-AllowSystemCertificateWarning` 只允许这条精确诊断，原日志保留并打印警告，其他脚本错误仍失败。本轮 ENet 测试使用该选项。
- 旧自动操作测试的 250 秒模拟时间预算在一次 8 球对局中到期，当时有效比赛时间仅 91.2/100 秒；继续到第 17,912 帧正常终场，最长单次死球阶段 14.9 秒，无死锁。把该测试总时限调整为 400 秒，仍强制检查自然终场，未改比赛时长或流程。
