# 操作与辅助设置

核对日期：2026-10-04。以 [football_input.gd](../space-football-demo/football_input.gd)、[desktop_input.gd](../space-football-demo/desktop_input.gd)、[match_tools.gd](../space-football-demo/match_tools.gd) 为准。采用 FIFA Classic 风格的核心攻防布局，不代表完整复制 FIFA 的所有操作。

## 比赛基础键位

键盘使用方向键移动；表中 Xbox 的 A / B / X / Y 指手柄按键，与键盘同名字母不同。

| 操作 | 键盘 | Xbox | 情境 |
| --- | --- | --- | --- |
| 移动、瞄准 | 方向键 | 左摇杆 | 键盘八方向归一化；摇杆连续角度 / 力度 |
| 短传 | S | A | 按住蓄力，松开出球 |
| 直塞 | W | Y | 持球或符合预输入条件 |
| 挑传 / 传中 | A | X | 持球，按住增加力度 |
| 射门 | D | B | 持球按住蓄力，松开射门 |
| 普通抢断 | D | B | 无球按下触发 |
| 原地铲 / 滑铲 | A | X | 无球，按起始速度选择姿态和滑行距离 |
| 冲刺 | 按住 E | 按住 RT | 消耗体力 |
| 护球 / 防守横移 | 按住 C | 按住 LT | 持球护球，无球贴防 |
| 切换球员 | Q | LB | 无球时使用 |
| 门将出击 | 按住 W | 按住 Y | 防守时，松开恢复正常职责 |
| 队友协防 | 按住 Z | 按住 RB | 防守时 |
| 防守 / 均衡 / 压上 | 1 / 2 / 3 | 十字键左 / 右逐档调整 | 改变队伍战术 |
| 取消待执行动作 | Backspace | 按下右摇杆 | 清理可取消的操作 / 接应 |

射门与抢断按“按下时的情境”确定：抢断夺球后再松开 D / B，不会意外补射。比赛中 WASD 不用于移动，空格不用于射门；菜单仍支持 WASD。

## 组合动作与配合

| 操作 | 键盘 | Xbox | 说明 |
| --- | --- | --- | --- |
| 搓射 / 弧线射门 | Z + D | RB + B | 保持修饰键，蓄力并松开射门键后再松修饰键 |
| 挑射 / 吊射 | Q + D | LB + B | 同样保持修饰键完成出脚 |
| 高空直塞 | Q + W | LB + Y | 在队友前方送高球 |
| 二过一 | Q + S | LB + A | 传球后原传球者前插 |
| 大力地滚球 | Z + S | RB + A | 更有力的传球 |
| 低平传中 | Z + A | RB + X | 区别于普通高传中 |
| 假射 | 蓄力 D 时按 S | 蓄力 B 时按 A | 取消真正射门并播放假动作 |
| 呼叫队友前插 | 轻点 Q | 轻点 LB | 进攻时，短按且没有被组合动作使用 |
| 呼叫靠近接应 | 轻点 Z | 轻点 RB | 进攻时；防守长按是协防 |
| 头球 / 凌空射门 | D | B | 来球高度可触及；按场景选择动作 |
| 高球摆渡 | S | A | 高球可触及的场景 |
| 解围 | A | X | 高球处理场景 |

轻点呼叫约以 260 ms 为短按界限。辅助、球高、是否已进入动作有效窗口会影响执行；不是每次按组合键都无条件产生对应触球。

## 方向技巧、定位球和回放

| 操作 | 键盘 | Xbox |
| --- | --- | --- |
| 无球定向切人 / 持球拉球变向 | 小键盘 8 / 2 / 4 / 6 | 右摇杆方向 |
| 趟球突破 | E + 上述方向 | RT + 右摇杆 |
| 更换定位球主罚 / 跑位方案 | 4 / 5 | 十字键上 / 下 |
| 跳过捡球等死球准备 | 长按 S 约 0.85 秒 | 长按 A 约 0.85 秒 |
| 跳过当前进球回放画面 | S / D / A / W 任一个 | A / B / X / Y 任一个 |
| 保存 / 重试训练场景 | F2 / F3 | 无专属快捷键，可用相应菜单功能 |

设置可将小键盘方向技巧替换为 I / K / J / L。死球跳过有逐渐充满的圆环，松键不会穿透成传球。跳过回放只退出本地回放画面，不擅自推进服务器的进球阶段。

F2 / F3 仅用于本地快速比赛的开发训练场景，保存模拟状态和随机数状态到当前进程内存，不是写入持久存档；重新开局后不可当成永久录像恢复。换人在比赛菜单申请，等待适合的死球执行。

## 菜单、暂停与设备

| 操作 | 键盘 | Xbox |
| --- | --- | --- |
| 移动菜单焦点 | 方向键 / WASD / Tab、Shift+Tab | 左摇杆 / 十字键 |
| 确认 | Enter / 空格 | A |
| 返回 / 关闭 | Esc | B |
| 比赛菜单 | Esc | Menu |
| 操作指南 | F1 | View |
| 全屏 | F11 | 界面按钮 |

- 菜单确认徽标位于按钮内部文字右侧；主要入口使用较大的徽标。禁用按钮跳过，弹窗焦点不进入底层，关闭后恢复选择。
- 搜索框输入 WASD 不导航；Tab 或上下键可离开输入。筛选框可用确认键轮换、左右键调整，鼠标仍可点击。
- 本地暂停停止比赛；在线菜单、帮助、辅助设置和换人界面不暂停权威比赛。
- 启动及热插拔识别控制器，显示名称和状态；最近有效键鼠 / 手柄输入切换提示，轻微摇杆漂移不切换。
- Xbox 优先；有 PlayStation、Nintendo、未知手柄的图标方案。Nintendo 按物理位置标示。设置覆盖的是图标，不是重新映射物理按键；其他品牌图标不代表对应硬件已全部实测。
- 丢球、切人、暂停、设备切换会清理蓄力及不再适用的待发动作。手柄断开时，本地比赛暂停，联机打开菜单并提交取消，服务器继续。
- 窗口失焦不接收手柄菜单输入。当前一人使用活动手柄，没有同机双手柄双人模式。

## 辅助与比赛选项

快速比赛阵容预览中新增“球场”“天气”“重力”按钮，鼠标点击或键盘 Enter / 手柄 A 循环选择。调整时保留当前阵容，重赛保留环境；说明文字即时展示比赛影响。见 [环境机制](MATCH_ENVIRONMENT.md)。

入口：主页设置 → 操作辅助与传球指示；本地暂停和在线菜单也可进入。默认标准辅助，偏好存于 `user://input-preferences.cfg`。

| 设置 | 档位 / 默认 | 实际作用 |
| --- | --- | --- |
| 总体辅助 | 低 / 标准 / 高；默认标准 | 传球目标方向锥与修正；切换总档同时重设接球、射门和自动切人子项 |
| 接球辅助 | 低 / 标准 / 高；默认标准 | 主动迎球程度，可单独调节 |
| 射门辅助 | 低 / 标准 / 高；默认标准 | 射门落点修正，可单独调节 |
| 自动切人 | 手动 / 接球队员 / 接球与自由球；默认接球队员 | 何时把操作权交给合适球员 |
| 传球方向指示 | 开 / 关；默认开 | 脚边小箭头显示辅助后的短传方向，出球后短暂显示真实方向约 0.3 秒 |
| 镜头冲击 | 关 / 轻微 / 标准；默认轻微 | 控制触球、射门等瞬时相机反馈强度 |
| 手柄震动 | 默认开 | 在支持设备上输出反馈 |
| 进球回放 | 默认开 | 本地呈现进球过程 |
| 室内附加规则 | 默认关 | 下一场应用额外计时、门将和累计犯规规则，详见玩法 |
| 技巧方向备用键 | 默认关闭 | 开启后使用 I / K / J / L |
| 按键图标 | 默认自动识别 | 可指定品牌图标，保持物理键位 |

低辅助约 15° 寻找目标并小幅修正；标准约 38°，高约 65°。标准 / 高允许无方向时选择队友，低档主要依赖朝向。接球辅助在移动中仍可迎球，明显反向可让出操控；手动切人和取消终止接应，拿到球后不自动带跑。

方向指示器开关不改变传球计算；蓄力射门时隐藏，菜单不显示。辅助不自动射门 / 抢断，不提高球员基础能力。联机双方可以独立选择辅助，服务器校验执行；在线菜单和输入超时时不继续自动迎球。

## 安卓预留入口

[input_provider.gd](../space-football-demo/input_provider.gd) 定义 `sample()` / `reset()`，通过 `football_input.gd.external_provider` 接入统一指令。已有移动、冲刺、横移、动作、瞄准、战术、力度、修饰键及换人等字段。

后续适配器还需实现多指归属、虚拟摇杆、蓄力松开、滑动瞄准、触摸取消、安全区和可调布局。当前未实例化移动适配器，没有可用触屏方案，也未进行安卓测试 / 打包。
